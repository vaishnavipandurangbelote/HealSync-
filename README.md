## 💡 About the Project

**HealSync** is a Python-based health tracker application developed as an academic mini project. It aims to promote health awareness by helping users explore common symptoms, understand basic health-related information, and discover general wellness and Ayurvedic home-remedy suggestions.

Designed with simplicity and accessibility in mind, HealSync provides a user-friendly graphical interface and supports basic offline functionality, making health-related information easier to explore.

## ✨ Key Features

- 🩺 **Symptom Exploration** – Select symptoms and explore related health information.
- 🌱 **General Remedies** – Provides general wellness and Ayurvedic home-remedy suggestions.
- 👤 **Personalized Inputs** – Accepts details such as age, gender, and weight for informational output.
- 🧠 **Health Awareness** – Encourages awareness of physical well-being and common symptoms.
- 🖥️ **User-Friendly Interface** – Simple graphical interface built using Tkinter.
- 📡 **Offline Accessibility** – Basic functionality can be accessed without continuous internet connectivity.
- 🌐 **External References** – Access additional health information through external resources when internet is available.

## 🚀 Getting Started

Follow these steps to run HealSync on your local machine.

### Prerequisites

- Python 3.x
- Tkinter (usually included with standard Python installations)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/vaishnavipandurangbelote/HealSync-.git
```

**2. Navigate to the project directory**

```bash
cd HealSync-
```

**3. Run the application**

```bash
python code21.py
```
