# HealSync – Health Tracker App

HealSync is a Python-based health tracker application developed as an academic mini project. It aims to promote health awareness by helping users explore common symptoms, understand basic health information, and discover general wellness and Ayurvedic home-remedy suggestions.

The project focuses on making health information accessible through a simple graphical interface and supporting basic wellness awareness.


## Features

- **Simple GUI:** Easy-to-use graphical interface built with Python Tkinter.
- **Symptom Selection:** Allows users to select symptoms for basic informational guidance.
- **Health Information:** Provides basic descriptions and information related to selected symptoms.
- **General Remedies:** Displays general wellness and Ayurvedic home-remedy suggestions.
- **Personalized Inputs:** Supports user details such as age, gender, and weight for the application's informational output.
- **Offline Accessibility:** Basic application functionality is available without requiring continuous internet access.
- **External References:** Provides access to external health information resources when internet connectivity is available.

## Technologies Used

- **Python 3** – Application development and functionality
- **Tkinter** – Graphical User Interface (GUI)
- **File Handling / Local Data** – Supporting application data
- **Visual Studio Code** – Development environment

## How to Run

### Prerequisites

- Python 3 installed on your computer
- Tkinter available with your Python installation

### Steps

1. Clone this repository:

   ```bash
   git clone https://github.com/vaishnavipandurangbelote/HealSync-.git
   ```

2. Navigate to the project folder:

   ```bash
   cd HealSync-
   ```

3. Run the application:

   ```bash
   python code21.py
   ```
